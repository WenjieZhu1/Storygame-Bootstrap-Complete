DUNGEON ADVENTURE - BOOTSTRAP ASSIGNMENT
=======================================

FILES (KEEP IN THE SAME FOLDER)
- index.html : Home page with Bootstrap form and grid
- game.html  : Original dungeon story game with Bootstrap grid and navbar
- about.html : About Me page with Bootstrap grid
- style.css  : Custom styling for all three pages
- script.js  : Original six scenes plus Bootstrap styling for choices and stats

TEST

2. Open index.html in a browser while connected to the internet.
3. Enter a name, choose a role and click Start Adventure.
4. Use the Home, Game and About Me links on all three pages.
5. Test both story outcomes and the Restart Game button.
